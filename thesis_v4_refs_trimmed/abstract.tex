{
UK public procurement moves roughly \pounds300 billion a year, and a losing
bidder's challenge to an award is slow, expensive, and usually settled
long before a judge sees it. This project asks whether interacting large
language model agents can usefully simulate such a dispute, and how their
output should be evaluated when ground truth is scarce and the model can
invent evidence.

Three negotiating agents (a Contracting Authority, an Aggrieved Bidder, and
a Court modelled on the Technology and Construction Court), plus a
non-negotiating summariser, run on LangGraph over a locally hosted Llama
3.1, specified through prompt engineering and context injection, not
fine-tuning. The Court agent runs a conditional verification
protocol: it recomputes a scoring calculation exactly when the case
supplies a formula and every input it needs, and otherwise conducts a
qualitative review where writing down an unstated number is prohibited.
An extraction stage turns real judgments into structured scenarios, and a
rule-based pre-award risk screen addresses the industrial partner's actual
request: prevention, not replay.

Evaluation covers 23 verified UK judgments and over 400 logged
negotiations. Six merits scenarios were found stating the real court's
decision; once rewritten, the system matches it in 12 of the resulting
leak-free 14, missing a case decided on a different legal argument and one
reasoning correctly about a real mechanism but reaching the wrong
conclusion. Structural repair was needed on 5 of 4,515 responses, and a
widened screen confirms 13 Court-originated numeric fabrications across
four cases, each an invented input computed correctly. Two findings matter
more than any headline: a majority-class heuristic, a naive zero-shot
prompt, and the full pipeline all converge on the same 5-of-6 leak-free
accuracy, so the architecture cannot be defended on accuracy; and removing
the Court agent deadlocks all 18 runs, where it can be.
}
